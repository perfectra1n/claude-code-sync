Module merge_tool 

Source
Expand description

External three-way merge for a conflicting file.

Launches the configured merge_tool on the local and repo versions and waits for the merged result, so a conflict can be resolved rather than having one side discarded. External three-way merge for a differing file.

The terminal picker can only choose a side. When merge_tool is configured, the prompt gains “merge in the editor”: the tool runs as <merge_tool> <local> <remote> <base> <output> (the JetBrains argument order) and whatever it writes to the output pane is what lands.

A tool that keeps its window open until the merge is done (meld, kdiff3, vimdiff) is waited for, and its exit code decides whether the output pane applies. Editor launchers instead hand the request to an already-running process and exit successfully before the window is drawn; for those the output file being rewritten and then settling is what completion means.
