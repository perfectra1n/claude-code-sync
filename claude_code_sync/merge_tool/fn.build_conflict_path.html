pub fn build_conflict_path(local_path: &Path) -> PathBuf
Expand description

Build the next free Syncthing-style conflict-copy path: sibling of local_path named <stem>.sync-conflict-<YYYYMMDD>-<HHMMSS>-<host>.<ext> (UTC). A collision with an existing file takes the smallest free -1, -2, … suffix.
