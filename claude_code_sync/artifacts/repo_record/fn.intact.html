Expand description

Whether the record file on disk parses — with the CONCRETE value type, not serde_json::Value: a record whose values have the wrong shape (a hash where a set belongs, a bare string where a map does) is corrupt for its loader even though it is valid JSON, and a Value-typed check would wave it through while load silently reads an empty record. An ABSENT record legitimately reads as empty (the fresh-machine and upgrade path); a PRESENT but unreadable or corrupt one is not that — callers warn, because silently reading it as empty turns off everything the record protects.
