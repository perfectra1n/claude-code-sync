Expand description

Read-only classification of an artifact pull, computed BEFORE any write so the caller can snapshot the exact set of files that will change.

Fields§

§overwrites: Vec<PlannedWrite>

Local file exists and repo bytes differ: remote wins after snapshot.

§creates: Vec<PlannedWrite>

No local file yet: created, and recorded for deletion on undo.

§unions: Vec<PlannedWrite>

Union-merge targets whose local file would gain lines.

§mode_fixes: Vec<PlannedWrite>

Local files whose content already matches but whose executable bit does not: a chmod +x elsewhere, with nothing to rewrite.

§deletes: Vec<PlannedDelete>

Local files this machine synced before that the repo no longer has.

§unchanged: usize§skipped: usize

Repo files refused (denied names, unsafe paths).

§unmapped_projects: SkippedByProject

Repo files whose project this machine has no destination for, grouped by the project directory they came from, so the caller can warn once per project instead of once per file.

§tokens: PathTokens

This machine’s path tokens, so applying renders repo bytes the same way planning compared them.

§claude_dir: PathBuf

Where to record what this machine holds once the plan is applied.

§repo_root: PathBuf§merge_tool: String

The configured external merge tool, offered when a file differs.

§tracked_after: TrackedPaths

The repo paths this machine will hold afterwards, for the next pull to tell a deletion from a file it never had.

§tracks_deletions: bool

Whether any active category mirrors deletions. When none does, the record is left untouched rather than emptied.

pub fn is_empty(&self) -> bool

True when applying the plan would write nothing.

Source

pub fn paths_to_snapshot(&self) -> Vec<PathBuf>

Existing local files the caller must snapshot before applying (overwritten raw files, union-merged files and deletions — a snapshot is what makes undo pull able to bring a deleted file back).

The record of what this machine last synced is included whenever the pull would rewrite it, so undoing a pull restores the files and the record that describes them.

Source

pub fn created_paths(&self) -> Vec<String>

Local paths this pull will create; recording them as a snapshot’s deleted_files makes undo remove them again.
