repo_dir_name for a project directory under projects_dir. In use_project_name_only mode the name comes from the working directory a transcript in it records, the same name its sessions are pushed under: the encoded directory alone cannot tell shop-web from shop/web, and its last dash-separated piece would file this project’s memory and attachments apart from its sessions.
