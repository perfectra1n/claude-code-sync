pub fn ensure_nothing_uncommitted(repo: &dyn Scm) -> Result<()>
Expand description

Refuse to purge while the repository holds uncommitted work.

A repo-side transcript that is not committed yet — a push that was declined, a path an ignore rule covers — would be deleted with no copy in history, which is the one thing a purge promises not to do.
